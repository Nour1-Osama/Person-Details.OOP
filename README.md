# Person Class – OOP in C++

A simple C++ project created while practicing the basics of Object-Oriented Programming (OOP).

## About

This project contains a `clsPerson` class that stores basic information about a person and provides some simple operations.

The class includes:

* ID
* First Name
* Last Name
* Email
* Phone Number

It also provides methods to:

* Set and get personal information
* Print the person's information
* Send an Email
* Send an SMS

## OOP Concepts Used

* Classes & Objects
* Private Data Members
* Constructor
* Setters & Getters
* Encapsulation
* Member Functions

## Example

The project creates a `Person` object and uses its methods to display the person's information and simulate sending an email and SMS.
